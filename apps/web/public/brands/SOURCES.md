# Brand marks

Official marks, taken from each organisation's own published site. None are
redrawn or recoloured.

| File | Source |
|---|---|
| `hedera.svg`, `hedera-white.svg` | docs.hedera.com site logo (light and dark variants) |
| `world.svg`, `world-white.svg` | docs.world.org logo, `logo/world-developers.svg` and its white variant |
| `whitechain.png`, `whitechain-dark.png` | docs.whitechain.io `img/logo_light.png`, `img/logo_dark.png` |
| `whitechain-mark.png` | docs.whitechain.io favicon, resized to 128px |

`world.svg` and `world-white.svg` have only their `viewBox` and root size
changed, to show the symbol and the `world` wordmark and leave out the
`Developers` suffix of the original lockup. The paths are untouched.

The white World variant works through the file's own `--fill-0` custom property.
